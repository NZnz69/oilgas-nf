## 黏度（先确认类型！）

| 用户说法 | 引擎代号 | 类别 |
|---|---|---|
| X 厘泊 / X 厘斯**（易混，必须和用户确认）** | cP → 动力 / cSt → 运动 | 两类不同 |
| X 毫帕秒 / X mPa·s | mPa.s | viscosity_dynamic |
| X 帕秒 | Pa.s | viscosity_dynamic |
| X 平方毫米每秒 / X mm²/s | mm2/s | viscosity_kinematic |
| X 厘斯 / X cSt | cSt | viscosity_kinematic |

**高危提示**：厘泊（cP）是动力黏度、厘斯（cSt）是运动黏度，一字之差、
类别完全不同。用户说"厘"时必须确认是"厘泊"还是"厘斯"。

## 翻译规则

1. 用户原始表述在呈现时**回显**（"您输入的'每小时100方'已按 m3/h 处理"）；
2. 表中查不到的别名 → 向用户确认，禁止猜（猜错单位等于改数据）；
3. 数值不翻译、不改写、不舍入——只翻译单位代号。
