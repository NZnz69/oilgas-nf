# NF 身份模板（安装向导 Step 6 使用）

安装向导引导用户四选一后，将结果写入本机长期记忆（USER.md）：

```
NF身份：学生（或 专业教师 / 场站运维人员 / 工程设计人员）
NF身份确认日期：YYYY-MM-DD
```

## 身份选项说明

| 身份 | 主推场景 | 适合人群 |
|---|---|---|
| 学生 | 规范查询、公式计算与参数解释、课设毕设引导、实验指导、复习自测 | 本科生、研究生 |
| 专业教师 | 题库与任务书生成、规范变更推送、清单抽查、案例转化 | 授课教师、实验指导教师 |
| 场站运维 | 故障排查、应急速查、高危作业清单、阴保判定、维保交底 | 场站与管道一线人员 |
| 工程设计 | 选型取值、工况校核、报审清单、版本状态、计算书 | 设计院工程师 |

## 规则

- 个人身份不硬编码进发行包（防多人共用串身份），由用户安装时或首次使用时选择。
- 跳过选择则首次使用时由 Skill 主动询问，体验一致。
- 身份随时可切换（一句话生效），个人记忆不随身份清零。
